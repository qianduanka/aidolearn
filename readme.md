# AidoLearn — Free Multilingual Learning Tools

AidoLearn is a lightweight, ad-free learning platform built for students, teachers, language learners and self-study enthusiasts around the world.
It provides structured knowledge trees, formula sheets, example explanations and interactive practice exercises.
No account, no login, no paywall. All learning content is accessible instantly in your browser.

🔗 Official Website: [https://www.aidolearn.com](https://www.aidolearn.com)

---

## ✨ Core Philosophy
- **Knowledge First**: Focus on clear knowledge frameworks, organized into tree-style catalogs for easier learning and review.
- **Multilingual Support**: Built for bilingual and multilingual learners. Content supports switching between different languages.
- **No Registration**: All learning resources and practice modules are open to use right away. No email required.
- **Clean & Minimal**: Distraction-free pages without pop-up ads or complicated navigation.
- **Browser-Native**: Static site powered by Cloudflare CDN, fast loading on both desktop and mobile devices.
- **Community Driven**: This is an indie side project. Feedback, content suggestions and error reports are highly welcomed.

## 🎯 Who is AidoLearn for?
1. **School Students**: Organized formulas, examples and exercises for daily review and homework.
2. **Language Learners**: Bilingual flashcards and sentence training for English and Chinese learning.
3. **Teachers & Tutors**: Quick open educational resources to use in class.
4. **Self-Learners**: Anyone who wants a simple, quiet place to study without distractions.
5. **Parents**: Easy learning materials for kids’ early bilingual education.
